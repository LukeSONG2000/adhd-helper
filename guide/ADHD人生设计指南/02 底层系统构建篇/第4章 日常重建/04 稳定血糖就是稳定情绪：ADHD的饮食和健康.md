# 稳定血糖就是稳定情绪：ADHD的饮食和健康

阅读本节后你将理解：

- 为什么血糖波动会让你的ADHD症状加重
- 你想吃东西的冲动可能不只是饿，而是大脑在寻求多巴胺
- 如何在不依赖意志力的前提下建立一个稳定的饮食模式
- 你不是需要更自律，你需要的是更稳定的血糖

## 一、我不吃东西的时候，整个人都不对了

饿的时候，你不仅仅是饿了——你会烦躁、焦虑、无法集中注意力、对一点小事就反应过度。身边的人可能学会了在你吃饭前不要惹你。你吃完一顿高碳水早餐（比如面包、粥、包子）之后，反而更困了。或者你忙了一整个上午忘记吃饭，到了下午开始手抖、心慌、大脑一片空白，然后你拼命吃了一大堆东西来补救。

你可能知道应该规律吃饭，但你也知道这对你来说特别难。但你可能不知道的是ADHD大脑对血糖波动的敏感度比普通人更高。

## 二、血糖：你的大脑最重要的燃料

你的大脑每时每刻都需要葡萄糖来运转。它不能储存能量，只能依靠血液中即时供应的葡萄糖。当血糖水平稳定时，你的大脑有足够的燃料来维持注意力和情绪调节。但当血糖水平剧烈波动时，你的大脑会进入燃料短缺状态，它的表现自然会下降。

血糖波动对你来说，可能意味着：

| 血糖状态 | 对ADHD大脑的影响 |
| --- | --- |
| 血糖稳定 | 维持注意力和情绪调节的能力相对稳定 |
| 血糖快速下降（饿过头） | 注意力下降、易怒、焦虑、脑雾、难以控制冲动 |
| 血糖快速上升（高碳水餐后） | 短暂清醒后出现餐后 slump：困倦、难以集中注意力 |
| 血糖剧烈波动（不规律饮食） | 情绪不稳定、能量起伏大、ADHD症状被放大 |

不稳定的血糖可能会让你的ADHD症状看起来更严重。你以为是ADHD加重了，也可能是你的大脑在燃料不足的状态下运作。

## 三、ADHD的饮食困境：不只是饿不饿的问题

你可能会发现，你的饮食问题不只是不规律，它和ADHD的几个核心特征密切相关。

困难一：多巴胺驱动的渴求

你吃的东西可能不只是为了吃饱，而是为了刺激。ADHD大脑对多巴胺的需求更高，而高糖、高脂肪、高碳水的食物能够迅速提供多巴胺刺激。所以你可能会在并不饿的时候想吃东西，或者在压力大的时候忍不住吃零食。这不是贪吃，这是你的大脑在寻求刺激，它用吃掉那个甜甜圈来回应我需要多巴胺的信号。

困难二：感知不到饥饿信号

你的内感知觉差，你可能不知道自己饿了——直到饿过头了才意识到。而你饿过头的时候，你已经处于低血糖状态了，此时你更容易冲动、更难做出好的饮食选择，也更容易暴饮暴食。

困难三：启动困难挡住了做饭这件事

做饭是一个涉及计划、采购、准备、执行、清理的复杂任务链。你的大脑看到这个任务链，可能就直接选择了不吃或随便吃点什么。

困难四：情绪化进食

当你情绪耗竭、焦虑、疲惫时，食物会成为一种快速可得的调节工具。它不能解决情绪问题，但它能暂时让你感觉好一点。于是你可能在压力大的时候吃更多，而在情绪低迷的时候完全吃不下。

## 四、你可以怎么做？（而不是更自律）

以下策略让你在不需要大量意志力的情况下，建立一个更稳定的血糖模式。

### 策略一：把血糖稳定放在吃得健康前面

很多人对健康饮食的理解是吃什么。但对ADHD大脑来说，什么时候吃比吃什么更重要。你可以先忽略应不应该吃碳水这类问题，先把重点放在让血糖不要剧烈波动上：

- 尽量在起床后1小时内吃第一餐
- 尽量每3-4小时进食一次（哪怕只是吃一点东西）
- 如果一顿正餐对你来说很难做到，用少食多餐代替，吃几口、吃点零食、喝点酸奶，都比什么都不吃要好

### 策略二：用低决策的饮食模式减少启动成本

你不需要每天决定今天吃什么。决策本身就是一种消耗。你可以：

- 准备2-3个默认早餐选项（比如鸡蛋+面包、酸奶+麦片），每天轮换
- 把一周的午餐/晚餐模式化（比如周一吃这类、周二吃那类），不需要完全固定，只需要减少到了饭点才想吃什么这个决策时刻
- 储备一些最低成本的备用食物——不需要加工、随手能吃的食物（坚果、酸奶、香蕉、鸡蛋），在你做不了饭的时候可以临时支撑

### 策略三：把稳定血糖和多巴胺需求区分开

当你想要吃高糖零食的时候，先问自己一个简单的问题：我饿了吗？还是我只是想吃点有刺激的东西？

- 如果答案是我饿了，吃一份能让血糖稳定的食物（蛋白质+少量碳水）
- 如果答案只是想吃点有刺激的东西，这不是饿，这是多巴胺渴求。你可以选择吃那个零食（不需要对自己说不），但同时意识到：我正在用食物来满足大脑的刺激需求。这种认知本身，就会慢慢改变你与食物之间的关系。

### 策略四：在能量低谷之前补充能量

如果你知道自己下午2-3点容易疲劳、注意力下降，那么在下午2点之前吃一点东西（而不是等到饿了才吃）。如果你知道自己晚上容易暴食，那么晚餐时多摄入一些蛋白质（增加饱腹感，减少晚间的糖分渴求）

如果你的内感知觉差，你不太容易意识到自己饿了，那么设置一个固定时间的能量检查点——比如上午10点、下午4点，不管饿不饿，先吃一小口东西，把感知饥饿这个依赖内部信号的任务，转化为定时补充这个依赖外部时间的任务。

## 五、重要的认知

你可能花了很多年时间责怪自己不能坚持健康饮食。但你可能没有意识到：你所面对的挑战比普通人复杂得多。

延伸阅读：为什么蛋白质对ADHD大脑有帮助？

蛋白质在消化过程中分解为氨基酸，其中一种叫做酪氨酸。酪氨酸是合成多巴胺和去甲肾上腺素的前体物质，这两种神经递质正好是ADHD大脑相对缺乏的。虽然饮食中的蛋白质不能直接“治疗”ADHD，但它能在一定时间内为多巴胺合成提供原料。

此外，富含蛋白质的食物消化速度较慢，能帮助血糖更平稳地上升和下降，减少餐后崩溃的发生。因此，把早餐换成高蛋白是一个值得尝试的策略，尤其是如果你发现高碳水早餐后会犯困。

实用做法： 如果早餐吃不下鸡蛋，试试酸奶、坚果、奶酪棒、或前一晚剩下的肉类，形式不重要，关键是有蛋白质。
