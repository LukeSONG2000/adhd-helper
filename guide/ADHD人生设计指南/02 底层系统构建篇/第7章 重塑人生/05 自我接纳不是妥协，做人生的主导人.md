# 自我接纳不是妥协，做人生的主导人

## 阅读本节后你将理解：

- [ ] 自我接纳不是放弃改变，是改变的前提
- [ ] 为什么接纳自己，不等于接受现状不变？
- [ ] 如何从和自己作战，转向和自己合作？
- [ ] 做自己人生的主导人意味着什么？

## 一、接纳自己意味着不用改变吗？

很多人听到自我接纳这四个字，第一反应是：那不就是躺平了吗？如果接纳了自己的拖延、自己的情绪化、自己的不自律，那是不是就再也不用改了？这是一个很常见的误解。

自我接纳不等于放弃改变。它指的是：不再用我本来应该更好/我怎么又这样的态度来对待自己。它说的是在改变之前，先承认此刻的自己是什么样子，而不是一边否定自己，一边强迫自己前进。

不接纳自己的改变，往往是勉强的、消耗的、难以持续的。而接纳之后的改变才可能是稳定的、有方向的、真正属于你的。

## 二、一直以来的自我斗争

你可能已经和自己作战了很久。这场战争的形式可能包括：

- 你告诉自己我应该能像别人一样，然后在你做不到的时候批评自己
- 你试图隐藏你的困难，不让别人看到真实的我
- 你对自己说这次我一定要坚持住，然后在放弃的时候感到羞耻
- 你不断提醒自己不要再犯同样的错误，但你还是会犯

很多ADHDer从小就在一种持续的自我斗争里长大。这种自我斗争看起来像是在督促自己变好，但实际上，它消耗了我们大量的精力。我们把本可以用在行动上的能量，花在了和自己对抗上。我们越是想通过责备来改变自己，越容易陷入疲惫、挫败、和更深的停滞。

## 三、真正的自我接纳

| 自我接纳不是 | 自我接纳是 |
| --- | --- |
| 放弃改变 | 改变的前提，你需要先承认现状，才能开始改变它 |
| 我就是这样，我没办法 | 我承认我目前是这样的，我可以在这个基础上做点什么 |
| 对问题的忽视 | 对问题的承认，你无法改变你拒绝承认的东西 |
| 不再努力 | 把能量从对抗转移到行动上 |
| 向现实妥协 | 承认现实，同时选择如何回应它 |

真正的自我接纳，是承认一件事：我的大脑就是这样运作的。它不完美，它有它的困难，也有它的特点。这不是一种消极的认命，而是一种更清醒的看见。当我们不再把大量的精力花在为什么我做不到上，我们才有可能开始问：那我适合怎么做？

接纳不是喜欢自己的所有表现，而是不再因为自己的表现而否定自己的存在。它允许我们看到困难，也允许我们寻找更适合自己的路径，而不是一直在原地和自己较劲。

## 四、当你自我斗争

当你停止与自己作战，一些变化可能会开始发生：

- 你不再因为忘记一件事而花一个小时批评自己，你可以选择用那些能量去弥补它
- 你不再因为分心而责备自己，你可以开始设计更容易返回注意力的环境
- 你不再因为社交后的疲惫而愧疚，你可以开始安排你需要的恢复时间
- 你不再因为三分钟热度而羞耻，你可以开始欣赏自己探索的能力

当我们停止自我斗争，会发生一些很微妙的变化。

首先，我们会省下大量的精力。那些原本用在自我批评自我怀疑自我对抗上的能量，可以被释放出来，用在真正想做的事上。

其次，我们会更容易看清自己的真实状态。当不再急着否定自己时，我们才有空间去观察到底卡在哪里？我需要什么？什么方式对我来说是有效的？

再次，我们会更容易允许自己有起伏。我们不再要求自己永远稳定，而是接受自己有时状态好、有时状态差，并且在偏离之后能更快地回来。

## 五、如何从作战转向合作？

步骤一：用观察代替评判

当你注意到自己在做一个习惯性的自我批评时，试着把它换成观察句：我迟到了。而不是：我又迟到了，我怎么总是这样。观察是事实，评判是附加在事实上的态度。不需要在观察到事实之后附加一个评判。你的自我批评可能已经成为一种习惯，它不一定真正能帮到你的。

步骤二：把能量从对抗转移到设计上

当你遇到一个反复出现的困难时，问自己：如果这个困难不消失，我可以为它设计一个什么系统？

当你再次遭到拖延困扰，不是自责自己怎么才能不拖延，而是去考虑拖延之后我怎么回到任务上。

当你有一次忘记要做的事情，或者忘记和朋友的约定，与其想怎么才能不忘记，不如考虑可以用什么工具让我更容易记得。

步骤三：承认你的限制，但不让限制定义你

承认这个部分对我来说确实很难，但我仍然可以选择如何应对它。承认困难不等于放弃行动。它只是让你在行动时不再假装困难不存在。

步骤四：这已经很棒了了

练习对自己说，这个程度已经足够了，我虽然不是完美地做到，但我在现有条件下做到了这个程度，这已经很棒了。标准不需要来自应该做到什么程度，标准可以定为：在现有条件下我能做到什么程度。

## 六、做自己人生的主导人意味着什么？

做自己主导人不是控制一切，不是要求自己永远正确永远高效永远不出错。而是指我知道自己的大脑是怎么运作的，我知道自己适合什么不适合什么，我为自己设计一种更适合我的生活方式，而不是一直试图把自己塞进别人的模板里。

做自己人生的主导人意味着承认自己的限制，也看见自己的可能性。意味着不再被正常的标准绑住，而是找到属于自己的节奏。我们需要的，是在理解自己的基础上，设计出一条属于自己的路。
