# 让你痛苦的缺陷，其实也是一种力量

## 阅读本节后你将理解：

- [ ] 为什么你一直把ADHD特质当作缺点
- [ ] 那些让你痛苦的特质，在另一种条件下可能是优势
- [ ] 如何从被迫承受不良影响，变成积极利用
- [ ] 有时不需要被修复，需要被重新理解

## 一、如果我能够不这么敏感就好了

你可能不止一次想过这句话。如果在被批评的时候可以不那么痛。如果在社交中可以不那么容易过载。如果能在拒绝面前不至于崩溃。如果能少一些冲动、少一些深夜的思绪翻滚、少一些对不公平的愤怒。

你可能觉得，这些特质是你生活中的障碍。你希望它们消失，或者至少变小一些。你花了很长时间试图控制它们、压制隐藏它们。但我想邀请你换一个角度：那些让你痛苦的敏感，可能不只是敏感。那些让你无法停止的思考，可能不只是想太多。那些让你比别人更强烈地感受到不公的愤怒，可能不只是反应过度。

它们可能是你的神经系统在以它的方式告诉你一些事，而当你学会如何与它们相处时，它们可能会变成你的一种能力。

## 二、那些被你当作缺点的特质，在另一种条件下可能是能力

敏感：你比别人更早注意到细微的变化

你可能总是注意到别人没有注意到的细节，别人的情绪变化、环境中的微小异常、语气中的微妙不同。这种敏感让你在社交中更容易捕捉到潜在的信息，在工作中更容易注意到问题，在关系中更容易察觉到不和谐。问题不在于敏感本身，而在于你的敏感没有筛选机制，它接收的信息量超过了你能够轻松处理的范围。当你有意识地管理它接收的信息量时，它就不再是负担。

冲动：你有一种快速反应的能力

你可能经常在别人还没反应过来的时候就已经行动了。有些情况下这带来了麻烦；有些情况下，这也让你能够在紧急时刻做出快速判断，或者在别人犹豫不决时迈出第一步。你的冲动不是没有思考，是思考的速度快到它看起来像没有思考。当你学会给这种快速反应设置一个微小的缓冲时，它可能会变成一种果断的能力。

过度专注：你有深度投入的能力

你可能在某些事情上表现出一种极端的专注，以至于忘记了时间、忘记了吃饭、忘记了周围的一切。这种状态可能让你在某些时候感到失控，但它也是一种能力。当你能把这种专注引导到对你重要的事情上时，它可能让你在别人分散精力时保持深度。

高度共情：你能感受到别人感受不到的

你可能常常感受到别人的痛苦、需要、未说出口的话。这种共情可能会让你在人群中感到疲惫，但它也让你成为能够理解他人的人。在一个许多人只关注自己的世界里，这种能力是稀缺的。

## 三、为什么有时候看不到这些？

你之所以看不到这些特质的力量，是因为你的生活环境一直要求你用它们不擅长的方式使用它们。

- 你的敏感在需要快速处理大量社交信息的环境中会被消耗，但在需要深度理解一个人的时候会变成能力。
- 你的冲动在需要按照固定程序工作的岗位上会变成麻烦，但在需要快速决策和灵活应对的时候会变成优势。
- 你的过度专注在需要同时处理多项任务的场景中会让你感到卡住，但在需要深度工作的任务中会让你产出远超常人。

问题不是你有这些特质，而是你一直在要求自己按照一套对大多数人的大脑的方式使用它们。

## 四、不是所有的特质都需要被修复

你可能一直有一个信念，觉得需要克服这些问题才能成为一个更好的人。但你有没有想过：有些你认为需要被消除的东西，可能只是需要被重新找到合适的位置？

- 你需要被修复的信念，可能来自一个你需要不断适应的系统
- 你需要被压抑的敏感，可能只需要一个更安静的容器来存放
- 你需要被控制的冲动，可能只需要一个更大的空间来运行
- 你需要被消除的过度专注，可能只需要一个方向，而不是一个停止

## 五、如何开始重新理解你的特质？

第一步：换一个框架来描述它们

你可能会说自己太敏感了。换一种说法是：我接收的信息比别人多。

你可能会说自己太冲动了。换一种说法是：我比大多数人反应更快。

每一个特质都是有双面性的，尝试换一个角度看待它们，会发现不一样的惊喜。

第二步：问一个不同的问题

与其问自己怎么才能不这么敏感，试着问什么环境下我的敏感是有用的。与其问我怎么才能不那么冲动，试着问什么场合下快速反应是一种优势。你的特质在不同的环境中会呈现不同的结果。问题不一定在于特质本身，而在于你目前所处的环境是否需要这套特质。

第三步：给自己一个空间来运行这些特质

你可能无法立即改变你的生活环境。但你可以在日常生活中为自己创造一个小空间，让你的一些特质以它们擅长的方式运作。比如在一个不需要快速切换注意力的任务中使用你的过度专注，或在一个不需要自我审查的关系中表达你的真实感受。

## 六、这一节的核心信息

| 你可能以为 | 实际是 |
| --- | --- |
| 我的敏感是一种弱点 | 敏感是你在接收信息，问题是信息量超过了你的处理能力，而信息接收能力本身就是一种资源 |
| 我需要变成一个不那么ADHD的人 | 你需要找到一个能让你的特质发挥作用的环境，而不是消除它们 |
| 我的特质让我无法成功 | 你的特质可能会让你在用不适合你的方式尝试时感到困难，这是方式不匹配，不是特质本身的问题 |
| 我应该为自己感到羞耻 | 你的特质在另一个条件下可能是很多人不具备的能力 |

你可能花了很多时间试图让自己符合一些不太适合你的标准。那些让你痛苦的敏感、冲动、过度专注，它们不是需要被消除的缺陷，它们是你需要学会使用的能力。你不需要改变自己来让生活更容易，你需要的是一个不同的视角来看待你已有的这些特质，以及一个更适合它们运作的环境。
