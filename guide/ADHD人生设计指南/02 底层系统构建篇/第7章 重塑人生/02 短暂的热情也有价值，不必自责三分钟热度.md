# 短暂的热情也有价值，不必自责三分钟热度

阅读本节后你将理解：

- 为什么ADHD大脑更容易产生三分钟热度式的热情？
- 短暂的热情不是失败，是一种特定的探索方式
- 如何区分需要深入和可以浅尝的事情？
- 重新定义完成和放弃的意义

## 一、我又放弃了，我就知道会这样

你有了一个新的兴趣，烘焙、摄影、一门新语言、一个副业创意。你非常兴奋投入了大量时间和精力，可能还买了相关工具。但是没过几周热情消退了，那些工具开始积灰，你不再提起那个项目，当别人问起时，你说还在弄或者最近太忙了。

然后你对自己说又半途而废了、我就是一个三分钟热度的人。你可能因为这种模式感到羞耻，甚至开始害怕开始任何新事物，因为你已经预设了结局：反正我也会放弃。

但我想邀请你换一个角度看待这件事：你的短暂热情也许不是失败。它可能是你大脑探索世界的方式。而你对自己的评判，可能比放弃本身消耗了你更多的能量。

## 二、为什么ADHD大脑更容易产生短暂但强烈的热情？

原因一：新鲜感本身就是多巴胺的来源

ADHD大脑对新鲜事物有更强的反应。当你遇到一个新兴趣时，它带来了大量多巴胺，探索、学习、想象未来的过程本身就充满刺激。在这个阶段，你不需要任何努力来维持兴趣，因为你的大脑正在奖励你。

原因二：你的兴趣驱动来自好奇，不是承诺

你可能不是那种先决定要做，再慢慢产生兴趣的人。你是被兴趣驱动，然后决定去做的人。这两者看起来相似，但背后的运行方式不太一样。前者是承诺导向的，后者是探索导向的。你的大脑更倾向于后者，而探索的终点不一定是一条直线，它可能是一个分叉路口。

原因三：维持兴趣需要的一种能力，是你的大脑不擅长的

当新鲜感消退、重复性增加时，维持兴趣需要执行功能，计划、持续投入、忍受无聊。这不是你的强项。所以当热情消退时，你很容易停下来。这不是放弃，这是一个可以预见的结果。

## 三、三分钟热度的真正价值

那些三分钟热度的经历，其实为你做了很多事情。

你获得了经验：

你通过三分钟热度的尝试，知道了烘焙需要什么、摄影的感觉怎么样、那门语言是什么样的、那个副业领域有什么规则。即使你没有继续，但是也获得了一种体验，而体验本身是有价值的。

你排除了不适合的选项：

有些事你之所以没有继续，是因为它们在尝试之后被证明不适合你。你不是放弃了它们，而是发现它们不适合。而这个过程本身就是有用的信息。

你满足了一种探索的需求：

ADHD大脑需要探索，就像需要睡眠一样，你的那些三分钟热度满足了你大脑对新鲜刺激和探索的需求。这些不代表你偏离正轨的，这是我们的大脑按自身的方式在正常运转。

你可能学会了知足：

有些兴趣不需要成为终身事业才值得被做。学了一点、玩了一下、了解了一些，然后放下了，这就可以是一个完整的体验。不一定代表失败，它只是代表已结束。

## 四、如何区分需要深入

不是所有兴趣都需要成为长期承诺。你可以用一种更轻松的方式来对待你的兴趣，而不是对每一个都要求自己坚持下去。

问自己几个问题：

- 如果我只了解这个兴趣的基础，我会感到满足吗？
- 我做这件事是为了长期使用，还是为了满足当下的好奇心？
- 如果我在这件事上没有成为专家，我会觉得这段经历没有价值吗？

如果你的答案是浅尝，允许自己浅尝。如果你的答案是我想深入，再考虑如何让它持续更久。

## 五、让兴趣持续更久

有些兴趣可能值得你投入更多时间，你可以尝试用以下方式让它持续更久一些：

方法一：允许自己间断地深入

你不一定需要连续不断地投入。你可以允许自己做一阵，停一阵再回来。这不是放弃，而是一种不同的节奏。你的兴趣可能不会在同一个时间段里持续增长，但它可以在更长的时间里累积。

方法二：让它在生活中保留一个入口

即使你暂时不做了，保留一个返回的可能：保留那些工具、保留你上次做到的位置。如果你有一天想回来，你不需要从头开始。

方法三：接受足够好的版本

你可能不需要成为专家。在某个领域拥有基础水平，然后在需要时知道去哪里获取更多信息，这本身就是一个有用的能力，这歌过程本身已经足够好了。

## 六、这一节核心信息

| 你可能以为 | 实际是 |
| --- | --- |
| 我放弃是因为我不够坚持 | 你的兴趣模式更偏向探索和体验，而不是长期的单一投入——这不代表你不行，只是说明你以不同的方式与兴趣互动 |
| 每一次放弃都让我更不相信自己 | 每一次尝试都让你更了解自己——了解哪些事可以浅尝、哪些值得深入。这些信息是积累，不是消耗 |
| 我应该等到真正感兴趣才开始 | 你可以在感兴趣的时候开始，在兴趣消退的时候结束——你不需要证明每一次开始都是正确的 |
| 三分钟热度是一种失败 | 三分钟热度是你在用探索的方式了解这个世界 |
