# 打破低配得感、讨好人格与完美主义的循环

## 阅读本节后你将理解：

- [ ] 低配得感、讨好和完美主义是如何形成铁三角的
- [ ] 为什么你总是觉得还不够好
- [ ] 讨好不是善良，是求生存的策略
- [ ] 如何开始从这个循环中迈出第一步

## 一、ADHD的习惯性等待

等我瘦下来，我就值得被爱了。

等我这次项目做好了，我就不用担心被批评了。

等我变成更好的自己，我就可以放松了。

这背后有一个你可能没有意识到的循环：你不相信自己本来就值得，所以你不断地用付出来证明自己值得。因为你总觉得自己还不够好，所以你拼命讨好、拼命完美。而因为你永远无法做到足够完美，这个循环就一直没有出口。

## 二、铁三角：低配得感、讨好人格和完美主义如何互相喂养

这三种模式很少单独出现。它们像三根互相支撑的柱子，共同构成了一面阻碍行动的墙。

- 低配得感： 我不值得被好好对待。
- 讨好人格： 我必须让别人满意，别人才不会离开我。
- 完美主义： 我必须做到毫无瑕疵，才不会被批评。

它们之间的循环是这样的：

1. 低配得感让你觉得自己不够好。你不相信自己本来就值得被喜欢、被接纳、被认真对待。你觉得别

人对我好，一定是因为我做了什么，而不是我本身就值得被好好对待。

2. 因为觉得自己不够好，你担心别人会离开你、批评你、否定你。于是你开始讨好——你说好的时候

比说不的时候多，你把自己的需求排在最后，你把别人的感受当作自己的责任。你以为这是善良，但更底层的声音是：如果我让别人不满意，他们就会离开我。

3. 同时，你也在用完美主义来弥补你的不够好。你觉得如果每件事都做到无懈可击，就不会被批评

了。于是你反复检查、反复修改、反复确认。

4. 当你无法完美的时候，低配得感再次被确认：你看，你就是不够好。然后你更努力地讨好、更拼命

地追求完美。

由于ADHD的神经独特性，生活里伴随的不确定性比普通人多，而这个铁三角循环，是很多ADHD为了在不确定的环境中获得安全感而发展出的应对策略。

## 三、为什么这些模式在ADHD中更常见？

ADHD是铁三角的高发人群，是因为在成长过程中接收到了一些特殊的反馈：

每次你犯错，除了你内心的自责之外，还有来自周围环境的反馈。这些反馈让你认为如果出错了，后果不仅是这件事本身的后果，还会有别人的评判、失望和离开。于是你需要完美，不是为了做得好，而是为了不被否定。

因为长期伪装和过度代偿的消耗，已经没有多余的精力去确认我本来的样子是否值得被接纳。

## 四、如何打破循环

打破这个循环不需要一次推翻全部，可以从一个小切口开始：

第一步：看到自己做了很多

当完美主义的自我批评出现时，你会盯着没完成的部分。但你可能忽略了：你已经在消耗大量能量在维持正常上。问自己一个问题：在同样的条件下，换一个人能做到多少？你会发现，你已经做得比合理预期更多。

第二步：练习对应该说不

当你意识到自己又在做一件出于应该的事情时，在心里问：如果我说不会发生什么？你会看到，害怕的那些后果（对方失望、对方离开、对方批评你）大部分都是你想象出来的。可以从一件小事开始，说自己需要想一想，然后观察对方是否真的因此否定你。

第三步：区分完美和足够好

完美主义让你盯着那1%的瑕疵，而忽略了99%已经完成的部分。可以用一个简单的标准来打断它：这件事如果交给一个普通人做，做到这个程度会被接受吗？如果答案是会，那就让这件事过去。不需要做到最好，只需要做到够用。

第四步：停止用讨好来换取安全感

如果你发现自己又在讨好别人，把别人的感受放在自己的感受之前，停一下，问自己：如果我不这样做，对方会真的离开我吗？如果答案是不会，那你的讨好只是在延续一个对你已经无用的旧有模式。

## 五、最重要的认知转变

不是先变完美才能被接纳。

不是先满足所有人才有资格休息。

不是先证明自己值得才能被爱。
