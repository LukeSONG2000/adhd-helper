# 为什么你知道该做，却动不了？对低刺激任务的生理性厌恶

## 阅读本节后你将理解：

- [ ] 为什么有些任务让你生理性反胃
- [ ] 拖延不是不重视，而是大脑的一种自我保护反应
- [ ] 内疚如何加重拖延，形成一个死循环
- [ ] 如何停止用我太懒了来解释一切

## 一、就是不想做，没有理由

有一件事你需要做。可能是一个表格要填、一封邮件要回、一份报告要写、一件衣服要叠。它并不难，甚至可能只需要几分钟。你知道它不难，你知道拖下去只会更糟，也没有在享享受拖延，只是无法让自己去碰它。

## 二、为什么大脑会抗拒某些任务？

ADHD大脑对刺激的需求阈值比普通人高。普通人能从完成一项任务本身获得足够的满足感，这是一种天然的多巴胺奖励。ADHD大脑从完成中获得的奖励信号较弱，所以它需要更多的刺激才能产生动力。

| 任务类型 | 对ADHD大脑的反应 | 动力反应 |
| --- | --- | --- |
| 高刺激任务 | （紧急、新奇、有趣、有挑战性） | 高 ：我现在就要做！ |
| 中刺激任务 | （有一定兴趣，但不紧急） | 中 ：可以做，但需要一点推动 |
| 低刺激任务 | （重复、枯燥、没有即时回报） | 接近0 ：我就是动不了 |

## 三、拖延的真正代价

很多人以为拖延最大的问题是事情没完成，拖延最大的代价是你在拖延过程中产生的自我攻击。

内疚不会让你终于去做，内疚只会让你更想逃避。你本来只是不想做那件事，但经过几轮自我攻击，变成了不想做那件事 + 觉得自己很差 + 没有能量做任何事。

## 四、逼自己往往无效

逼自己做低刺激任务，往往会产生一种厌恶条件反射：你把做这件事和痛苦联系在了一起，下次你的大脑会更强烈地抗拒它。

## 五、可以做什么？

方向一：给任务加刺激

把低刺激任务变成高刺激活动

- 打开计时器，设定3分钟，告诉自己只做3分钟
- 打开音乐，让声音的节奏感帮你推进动作
- 把任务当成成挑战：调战我能在10分钟内做多少？
- 和别人一起，激活行动力（Body double）

方向二：把任务切成最小可执行单元

整理房间是一个巨大的任务,但把任务拆小到不值得抗拒，就很轻松了。

- 不要想我要写完这篇文章 → 只想我要打开文档
- 不要想我要整理房间” → 只想我要把这张纸扔进垃圾桶
- 不要想我要开始运动 → 只想我要穿上运动鞋

方向三：切断循环的第一步是停止攻击自己

当你发现自己又在拖延的时候，停止用内疚自我攻击，拆掉了这个循环里最消耗能量的部分。

## 🧾今天的小实验：

找出此刻你在拖延的一件小事

- 如果是一封邮件 → 只写标题和开头
- 如果是一个表格 → 只打开文件，填一个格子
- 如果是一件衣服 → 只把它拿起来，叠好一只袖子
