# 为什么你总是很累：ADHD过度代偿和伪装

## 阅读本节后你将理解：

- [ ] 过度代偿是什么，为什么它让你看起来很优秀，却活得很疲惫
- [ ] 伪装的代价为什么如此沉重
- [ ] 这两种模式如何相互作用，让你陷入越努力越耗竭的循环
- [ ] 如何开始退出这场表演

## 一、ADHD好像一直在演一个正常人

在外人面前表现得很好，但只有你自己知道，维持这个形象有多累。你可能在出门前做了很长时间的心理准备；你可能在会议中一直提醒自己不要打断别人；你可能在社交结束后瘫在沙发上一动不想动，脑子里反复回放刚才说过的每一句话。这是在“过度代偿”。

## 二、过度代偿

过度代偿，是指ADHD为了弥补执行功能上的短板，额外付出远超正常水平的努力来维持表面的正常。

| 过度代偿的表现 | 真实代价 |
| --- | --- |
| 提前3小时起床，只为了有时间走神 | 持续睡眠剥夺 |
| 反复检查邮件5遍才发送 | 消耗3倍时间 |
| 把所有日程记在脑子里，不相信任何工具 | 认知负荷极高 |
| 社交中全程监控自己的言行 | 社交后彻底耗竭 |
| 从不拒绝任何请求，害怕被认为不靠谱” | 变得过度讨好 |

你用自己的方式撑到了现在。你以为这是正常的努力，别人也是这样做的吧？实际上，别人不需要在维持正常上消耗这么多能量。你一直在用更高的成本，做同样的事。很多研究也证实了这一点：ADHDer更倾向于内化自己的困难，并用加倍努力来掩盖它，也因此更晚才被识别出来。

## 三、伪装：你从什么时候开始演的？

与过度代偿紧密相关的是伪装（Masking）有意识地隐藏ADHD症状，让自己看起来正常。

伪装通常从童年就开始了。你可能很小的时候就发现：如果表现得乖一点、安静一点、努力一点，就不会被批评。于是你学会了：

- 在课堂上忍住不插嘴，把话咽回去
- 忘带东西时编一个“合理”的借口
- 假装听懂了其实没跟上的内容
- 情绪崩溃时躲起来哭，不让任何人看到

这些适应行为是聪明的，它们帮你在一个不理解你的环境里活了下来。但问题是，当你进入成年期，这种模式并没有自动停止，你依然在用隐藏真实反应的方式应对周围的世界。代价就是持续的、无法解释的疲惫。

## 四、为什么这两种模式对你伤害最大？

过度代偿和伪装之所以特别消耗能量，是因为它们不直接解决任何问题——它们只是掩盖问题。

| 你做的 | 实际在发生什么 |
| --- | --- |
| 花3倍时间完成任务 | 你掩盖了“启动困难”这个核心问题 |
| 在社交中拼命维持得体” | 你掩盖了“我需要更多安静时间”这个真实需求 |
| 从不拒绝、从不求助 | 你掩盖了“我也有极限”这个事实 |

这些掩盖让你看起来还行，但也让你身边的人无法看到你的真实需求。你越成功地掩盖，就越难获得真正的支持。同时你也在向自己传达一个信息：真实的我不够好。

你为别人眼中的你付出了太多，却很少为真实的你做点什么。

## 五、如何开始退出这场表演？

退出过度代偿和伪装不是突然不再努力，而是逐渐把能量从掩盖转移到调整上。可以做几件事：

步骤一：承认自己在硬撑

这可能是最难的一步。你不需要告诉任何人，但至少对自己承认：我在维持一种消耗巨大的状态。

步骤二：选择一个关系，试一次不伪装

不一定是最重要的关系——可以是一个你信任的朋友。在下一次你想说点什么但犹豫了的时候，说出来。看看会发生什么。你不会马上把所有面具都摘掉，但你可以先从一个小

的缺口开始。

步骤三：把维持正常的能量部分转移到设计系统上

停止问自己我怎么才能表现得更正常。开始问：这件事有没有更省力的方式来完成？ 这是对你能量最根本的重新配置。
