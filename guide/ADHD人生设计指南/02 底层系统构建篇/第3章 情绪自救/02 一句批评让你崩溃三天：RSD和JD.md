# 一句批评让你崩溃三天：RSD和JD

## 阅读本节后你将理解：

- [ ] 为什么一句随口的批评能让你崩溃三天
- [ ] 为什么看到不公时你的愤怒比当事人还强烈
- [ ] RSD和JD其实是同一个机制的两端
- [ ] 如何区分真实信号和误报

## 一、不就是一句话吗，你至于吗？

对方可能只是随口说了一句“你这个地方可以改一下”，你的心猛地一沉、脸开始发热、喉咙发紧，接下来的几个小时甚至几天，你都在反复回放那句话，反复想他是不是觉得我很差？我是不是根本不行？

或者，你看到有人在排队时插队、看到同事被抢了功劳、看到某个规则明显不公，你的愤怒瞬间涌上来，比当事人还激动，甚至忍不住当场说出来，事后觉得自己反应过度了。

## 二、RSD和JD：同一枚硬币的两面

RSD（Rejection Sensitive Dysphoria，拒绝敏感性烦躁）已经被越来越多地讨论。它指的是ADHDer对感知到的拒绝、批评或否定，产生强烈的、不成比例的情绪反应。

而JD（Justice Dysphoria，正义敏感性烦躁），是对感知到的不公正、不公平、规则被打破，同样产生强烈的、不成比例的情绪反应。

|  | RSD（向内） | JD（向外） |
| --- | --- | --- |
| 触发源 | 被拒绝、被批评、被否定 | 看到不公、规则被打破、他人被欺负 |
| 核心感受 | 我不够好、我被抛弃了 | 这不公平、我必须做点什么 |

| 典型反应 | 崩溃、退缩、自我攻击 | 愤怒、冲动发言、替别人出头 |
| --- | --- | --- |
| 共同根源 | 对社交信号和规则的高度警觉 + 情绪调节的生理性障碍 |  |

## 三、为什么我们的反应比别人快、比别人强？

这种反应在ADHD大脑中，有一个清晰的神经学路径：

1. 感知阶段： 你的边缘系统（杏仁核）对社交信号高度警觉。批评、拒绝或不公的信号被迅速接收并

放大。

2. 触发阶段： 边缘系统在毫秒内激活战斗或逃跑模式。身体进入应激状态：心跳加速、肾上腺素飙

升、前额叶皮层（理性脑）被抑制。理智还没反应过来，身体已经做出了反应。

3. 持续阶段： 由于情绪刹车（前额叶皮层对边缘系统的抑制）信号在ADHD大脑中传导较慢，这种反

应会持续更久。别人5分钟平复的情绪，我们可能需要2小时、一整天，甚至几天。

4. 放大阶段： 事后的反刍思维（“他说那句话是什么意思，我是不是反应过度了”）会进一步激活同

一个警报系统，让情绪反应像回声一样在体内反复震荡。

## 四、RSD和JD如何影响生活

RSD的代价：

你可能会为了避免被拒绝而不敢提出真实需求；为了避免被批评而过度努力，反复检查、反复修改；为了避免被拒绝的提前预演，在别人拒绝你之前先拒绝别人；或者为了确保对方不离开你而牺牲自己的边界、需求、甚至人格完整性。你容易被情绪裹挟，过早放弃或过度反应，而这些反应又在强化你“我不够好”的自我叙事。

JD的代价：

你可能是那个总是站出来替别人说话的人，但事后自己陷入疲惫和羞耻，觉得其实不关自己的事，自己似乎有些太激动了；你可能会在职场或社交场合因为反应过度，而被认为情绪化或难以合作；你可能会因为无法忍受不公而频繁冲突，消耗大量情绪能量。

## 五、RSD和JD不是你的敌人——它们是过度敏感的警报系统

这里有一个重要的视角转换：对被拒”和不公正的敏感，不是完全没有价值的。你之所以对不公平如此敏感，是因为你比其他人更快注意到它。你之所以对拒绝如此敏感，是因为你比别人更重视关系和连接。只是这个敏感的警报系统，在我们这里响得太频繁太持久。

你不需要消灭这个警报系统。只需要学会：

1. 识别它： 当情绪反应发生时，对自己说：这可能是RSD/JD在报警，不一定是事实。你不需要否定

情绪，只是把情绪和事实先区分开。

2. 延迟回应： 在情绪高峰时不做决定、不发声、不回应。给自己一个缓冲。你可以说“我需要想一想

再回复你”，然后等前额叶皮层重新上线。

3. 寻找替代解释： 当RSD响起时问：除了觉得对方讨厌自己的推测，还有没有其他可能性？当JD响起

时问自己：这件事真的需要我来处理吗？还是我的警报系统在过度反应？

4. 事后复盘： 情绪平复后问自己事实是什么？我的感受是什么？这两者的差距有多大？

回答这这些问题本身，就是让你的前额叶皮层重新上线参与对话。不必立刻消除警报，因为这个过程已经把警报声关小了。
