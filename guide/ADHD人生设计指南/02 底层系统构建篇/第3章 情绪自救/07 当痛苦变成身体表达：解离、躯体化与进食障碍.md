# 当痛苦变成身体表达：解离、躯体化与进食障碍

## 阅读本节后你将理解：

- [ ] 解离是什么，为什么你会灵魂出窍的感觉
- [ ] 身体疼痛可能不只是身体的问题
- [ ] 厌食和暴食如何成为ADHD被压抑的表达
- [ ] 如何开始重新建立与身体的连接

## 一、你的身体一直在替你说话

作为一个ADHD，你可能比其他人更难读懂身体的信号。因为你可能在更早的时候就被要求别那么敏感、别想太多。于是你学会了忽略身体的警告，而身体并没有停止说话，它只是换了一种方式表达。它用解离让你暂时逃离无法承受的压力，用躯体疼痛让你不得不停下来，用进食障碍来表达那些你说不出的话。

## 二、解离：当大脑不在线

解离是ADHD常见但很少被讨论的一种体验。它是大脑在压力过大时启动的一种保护机制，把你从当前的体验中断开连接。

解离可能表现为：

- 你坐在那里，但感觉自己像在从远处看自己
- 别人在跟你说话，你听到声音，但感觉像隔了一层玻璃
- 你开车回家，但完全不记得路上发生了什么
- 你正在经历一件痛苦的事，但感觉自己不在场，像一个旁观者
- 你看着镜子里的自己，感觉有点陌生

解离不是走神，走神是你还在当下，只是注意力漂移了。解离是你从当下退出了。ADHD代偿者倾向于内化痛苦，而长期内化会提高解离的发生率。解离在保护我们，但它也同时在阻止我们与生活真正接触。

## 三、躯体化：身体在替你说话

躯体化是指心理上的痛苦以身体症状的形式表现出来

躯体化在ADHD中可能表现为：

- 压力大的时候胃痛或消化不良
- 情绪波动时头痛或偏头痛
- 长期不明原因的疲劳或全身酸痛
- 心慌、胸闷、呼吸不畅
- 皮肤问题：湿疹、皮疹在压力期加重

躯体化的原因之一，是内感知觉差。当读不懂身体的早期信号，于是身体会用更剧烈的方式（疼痛、症状）强迫我们注意。由于长期压抑情绪的表达，我们的身体成为了情绪的容器。当容器满了，它就开始用症状来释放压力。

## 四、进食障碍：我说不出的，我的身体在表达

厌食和暴食，在ADHD中比大多数人意识到的更常见。它们表面看起来是饮食问题，核心是用食物来调节无法用语言表达的情绪。

厌食（限制性进食）：控制食物=控制不可控的生活

当外部世界不可预测、当你无法控制ADHD带来的混乱时，食物成为唯一可控的东西。限制进食不是想瘦，而是一种对失控感的回应：至少我可以控制这个。ADHD的冲动性让你在很多领域感到失控，而不吃成了你为数不多能坚持的规则。同时，低配得感也可能在其中起作用：我不值得被好好喂养。

暴食：用食物来填补无法命名的空洞

暴食不是贪吃，也是一种情绪调节的尝试。当焦虑、孤独、空虚、疲惫无法用语言表达时，食物提供了一种快速的感官刺激。咀嚼、吞咽、味觉——这些能暂时让大脑安静下来。暴食之后的羞耻感，又会触发新一轮的暴食，形成一个自我延续的循环。在ADHD大脑中，这一循环更容易建立，因为你对刺激的渴求更高，同时冲动控制更弱。

在ADHD中，暴食和冲动性存在显著关联。这意味着：当你冲动性较高时，即使你知道自己不该吃，你的行动可能仍然先于你的判断。

## 五、新的语言来和身体说话

1. 重新学习感知身体信号
- 每天一次，停一分钟，闭上眼睛，问自己：我现在身体感觉怎么样？
- 不要评判，只是觉察——不需要改变任何东西
2. 区分饥饿和需要
- 当你感觉想吃东西的时候，问自己：我饿吗？还是我在用食物处理某种情绪？
- 如果答案是我在处理情绪，试着用非食物的方式给身体一个信号：一杯温水、深呼吸、一块毯子
3. 允许身体表达，而不是管理它
- 哭是可以的、生气是可以的、不想说话是可以的。
- 身体的表达不需要被批准，你只需要让它在不伤害你和他人的前提下，安全地发生
4. 学会寻找帮助

如果你的进食障碍已经影响到你的身体安全（持续体重下降、闭经、脱发、频繁暴食后的催吐）请考虑寻求专业支持，这是一个需要被认真对待的健康问题。

重要说明：

如果你正在经历严重的进食障碍（持续体重下降、闭经、频繁催吐、无法控制的暴食循环），请寻求专业帮助：营养科、心理科或精神科。本手册不能替代专业医疗诊断。进食障碍是可以用专业方法处理的，不需要一个人扛着这一切。
