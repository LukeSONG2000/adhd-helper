# 长期任务坚持不下去：设计正反馈，让进展变得可见

## 阅读本节后你将理解：

- [ ] 为什么长期任务对ADHD大脑来说特别困难？
- [ ] 反馈延迟如何削弱你持续做一件事的动力
- [ ] 如何为长期任务安装即时反馈系统？
- [ ] 奖励和任务绑定的具体操作方式

## 一、你知道这件事很重要

ADHD大脑对即时反馈的需求比普通人更高。当一个任务需要很长时间才能看到结果，你的大脑会在这个过程中逐渐失去动力。它不是不重视那个结果，它只是在等待反馈的过程中耗尽了继续的燃料。所以我们的大脑需要一个更短的反馈回路。

## 二、反馈延迟削弱行动力

反馈延迟，是指你做了一个动作之后，需要等待一段时间才能看到结果。对ADHD大脑来说，反馈延迟越长，执行动力就越弱。

| 反馈类型 | 例子 | 对ADHD大脑的影响 |
| --- | --- | --- |
| 即时反馈 | 玩游戏时每次操作都有反应、发消息后立刻收到回复 | 动力持续，容易持续投入 |
| 延迟反馈 | 写一篇文章要几天后才能发布、学习几个月后才能看到成绩 | 动力逐渐下降，需要额外能量维持 |

## 三、如何为长期任务设计即时反馈？

核心思路是：把一个大反馈拆分成多个小反馈，让每一个小步骤都有一个可感知的完成感

方法一：物理标记法

每完成一个小步骤，就做一个物理标记。比如：在纸上打个勾、撕掉一张便利贴、把一个物品从一堆移到另一堆。这种物理动作本身就是一种即时反馈。

方法二：进度可视化

把你的进度画出来。一个简单的进度条、一堆积木、一排格子，任何可以让你看到自己完成了多少的东西。当你看到进度在移动时，就知道自己在前进。

方法三：分段庆祝

每完成一个阶段给自己一个已完成的信号。不一定需要大的奖励，一个小动作就够了（站起来伸个懒腰、对自己说这一段完成了、喝一口水）这个动作标记了一个完成点。

## 四、用任务绑定来建立执行路径

任务绑定是指：把一件不想做的事和一件会做的事放在一起执行，利用已有的行为模式来带动新的行为。

绑定的公式：做完 [我本来就会做的事] 之后，我就做 [我想建立的新动作] 。

例子：

- 每天刷完牙之后，就写一行今天的任务清单
- 每天坐下来吃早餐的时候，就打开文档写100字
- 每天晚上关灯之前，就整理一下明天的三件事

这种方式的优势在于：你不需要每次都决定开始那个新动作，因为你已经有一个固定的触发点。触发点是自动发生的，你不需要花费额外能量来决定现在开始做它。

## 五、如何设计对你有效的奖励

奖励对ADHD大脑来说是有效的，但前提是它的设计方式正确。

原则一：奖励要即时，不能等太久

我们需要的奖励应该是今天、甚至此刻就能获得的。写满一页就去泡杯茶是有效的，写完一整章就去吃顿好的也是有效的，因为它的反馈周期足够短。完成这个项目后去旅行对ADHD来说效果不大，是因为反馈周期偏长了，我们的反馈系统更倾向于即时或短周期奖励。

原则二：奖励要具体，不能模糊

做完这件事给自己一些奖励，这个太模糊了。我们需要的是一眼就能看懂的奖励：做完这一部分之后，我就可以看一集想看的剧。如果你在开始之前就知道奖励是什么，它就会成为驱动力的一部分。

原则三：奖励不需要很大

一个简单的、低成本的小奖励，可以比一个遥远的大奖励更有效。因为你不需要攒很久才能获得它，它就在你的下一个行动点等着你。

## 六、你不需要喜欢任务才能完成它

你可能一直有一个信念：当你找到热情的时候，你就能自然地完成事情。但你不需要喜欢一项任务才能完成它。你只需要一个能让你在过程中持续获得前进信号的系统。

| 旧路径 | 新路径 |
| --- | --- |
| 我需要喜欢这件事 | 我可以为这件事设计一个让我获得进展感的系统 |
| 我需要等到完成后才有成就感 | 我可以在每一个小步骤中创造“完成信号” |
| 我需要坚持到终点 | 我只需要完成下一个可标记的小单元 |

正反馈系统的目的是让你在完成之前就能看到你在前进。 不需要等到终点才知道自己走对了路。
