# 为什么ADHD容易陷入失衡的亲密关系

阅读本节后你将理解：

- 为什么ADHD更容易在亲密关系中陷入单方面付出的模式？
- 过度讨好和关系失衡如何互相喂养
- 失衡关系对你的能量和自我的消耗
- 如何开始转向更平衡的亲密关系模式？

## 一、我付出了很多，但我觉得自己越来越渺小

你在一段亲密关系中，你很在乎对方。你花很多时间考虑对方的需要，你调整自己的安排来配合对方，你尽量不让对方失望。你做这些不是因为你被要求，而是因为你希望这段关系好。但慢慢地，你发现自己在这段关系中的空间越来越小。你越来越难说不，越来越难表达自己的需求，越来越不确定自己在这段关系里到底想要什么。

## 二、为什么ADHD更容易陷入失衡关系？

失衡关系不是一种偶然。它往往是几种ADHD常见的思维和行为模式共同作用的结果。

因素一：讨好先于你的判断

当你在意一个人时，你可能本能地先进入让对方满意的模式。你不太确定这段关系是否安全，但你确定如果让对方失望，我可能会失去这段关系。于是你优先选择了付出，而不是先评估这段关系是否值得你这么付出。

因素二：冲动性让你先付出再思考

你可能在还没有看清一个人是否值得信任的时候，就已经投入了很多。你出于好意付出，你觉得对别人好是好的，但你可能会在不确认对方是否也会同等对待你之前，就已经给出了你的精力、时间、关注和情感。付出本身没有问题，问题是当付出显著多于你所获得的回应时，这段关系就开始消耗你。

因素三：被拒绝的敏感让你回避冲突

在亲密关系中，表达真实需求可能意味着暴露自己的脆弱。如果你不确定对方会如何回应，你可能会倾向于不表达，因为你害怕表达需求后被拒绝、被否定、被视为太麻烦。于是你选择继续付出，而不是开口要求改变。

因素四：低配得感让你觉得不值得被好好对待

你可能在内心深处有一种感觉：我需要做很多才能让一个人留在我身边。你认为自己需要付出额外的努力才能值得被爱。这意味着你在关系中更容易接受不平等的对待，因为你觉得现状已经不错了，你觉得知足。

## 三、失衡关系的信号：如何判断你正处于这种模式中？

如果你不确定自己是否处于失衡的关系中，可以看看以下描述是否适用：

| 信号 | 说明 |
| --- | --- |
| 你经常为对方的情绪负责 | 你觉得对方的情绪是你的责任，如果TA不开心，那一定是我做错了什么 |
| 你很少主动提出自己的需求 | 你习惯等对方问，或者干脆不说，因为说了也没用，或说了会让对方不高兴 |
| 你付出的方式在对方那里不会被反过来执行 | 做了很多如果是我，我会希望被这样做的事情，但对方可能不需要、不感激、也不回报 |
| 你感到在这段关系中越来越小 | 你开始不确定自己在这段关系中还剩下多少自主权，你需要问自己我还可以有自己的想法吗 |
| 你经常用至少来安慰自己 | 至少TA还愿意和我在一起，至少TA没有离开 |

如果你在几项上看到了自己，不一定意味着这段关系是坏的，但它意味着你可能正在用超出自己能力的方式维持它。

## 四、失衡关系的代价是什么？

失衡关系最直接的代价是能量消耗。你在关系中的付出显著多于获得，这本身就会持续消耗你。但你可能会忽略另一个更长期的代价：你的自我在变小。 你越来越不确定自己的需求是什么，你越来越难区分我想要和我应该，你越来越需要对方的反馈来确认自己是有价值的。你不只是在失去能量，你在失去和自己之间的联系。

失衡关系的另一个代价是：它让你无法进入更平衡的关系。当你习惯了通过过度付出来换取关注，你可能会错过那些愿意以平等方式与你相处的人。你不是在维持关系，你是在维持一个已经不适合你的模式。

## 五、如何开始转向更平衡的关系模式？

第一步：承认你在维持一段关系

你感到自己需要持续努力才能让这段关系保持在当前状态吗？如果是，你可能正在维持，而不是在一段关系里在场。承认这一点不是放弃关系，而是承认你目前的模式已经达到了它的极限。你需要一个新的方式来处理这段关系。

第二步：从小处开始表达需求

你不需要在重大问题上立刻做出改变。在一件小事上练习表达你的需求。“我今天不想出去吃饭”“我需要一个安静的时间”“我想在这件事上做不同的选择”。观察对方如何回应你的表达。如果对方能够接受你所说的内容，你就在学习：表达需求不一定会被拒绝。

第三步：区分付出和过度付出

在关系中为对方做事本身不是问题。问题在于你是否在用自己的能量来填补对方的空间、维持对方的舒适、避免对方的不满。一个简单的判断标准：如果你停下来一段时间，你付出的那些部分是由谁来完成的？

第四步：允许对方对你付出

你可能不太习惯接受对方的帮助。你可能会说没关系我自己来，或者你可能会感到需要回报对方。试着在一件事上允许对方为你做点什么，而不立刻要求回报。接受付出本身就是一种练习，它让你体验被给予是什么感觉。

## 六、一个重要的区分

| 健康的亲密关系 | 失衡的亲密关系 |
| --- | --- |
| 你表达需求，对方回应 | 你隐藏需求，希望对方猜到 |
| 双方都可以说不” | 只有一方可以说不 |
| 付出是相互的 | 付出是单向的 |
| 你们都有独立的空间 | 你越来越不确定自己独立时的样子 |

平衡的关系不需要完美，但需要存在相互性。这种相互性不一定在任何时候都是等价的，但它需要大致在一个可感知的范围内存在。如果你发现自己在这段关系中持续地消耗，而对方没有用相应的方式回应你的需求，你就已经看到了一个需要调整的信号。
