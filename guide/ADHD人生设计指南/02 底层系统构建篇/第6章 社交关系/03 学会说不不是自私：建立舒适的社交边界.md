# 学会说不不是自私：建立舒适的社交边界

## 阅读本节后你将理解：

- [ ] 为什么ADHD特别难以建立和维持社交边界？
- [ ] 边界不是拒绝别人，而是保护自己的能量
- [ ] 如何在不伤害关系的前提下表达你的边界？
- [ ] 从小处开始的边界练习

## 一、我只是不太会拒绝人

当别人向你提出请求、帮忙、出席、承担额外的任务你几乎总是答应。不是因为你愿意，而是因为你找不到合适的理由说不。你担心拒绝会让对方失望不喜欢你、觉得你不靠谱。但是你说好，会感到一种轻微的持续的消耗。时间精力和注意力，被分散到越来越多你并没有真正选择去做的事情上。

## 二、为什么ADHD特别难建立边界？

建立边界对任何人来说都不容易。但对ADHD来说，有几个额外的因素使这件事变得更困难。

因素一：被训练成了乐于助人

从小你可能被期望成为那个懂事的孩子，愿意帮忙、不添麻烦、不让人失望。学会了把自己的需求放在后面，因为你被告知这是善良和体贴，这个训练在你意识到之前就已经完成了。成年后你仍然按照那个模式运行，即使它已经不再适合你的生活。

因素二：先答应再后悔

当别人提出请求时，你可能在还没有完全考虑清楚之前就说了好。不是因为你想好了，而是因为对方正在看着你，而你需要给出一个回应。你答应了之后，然后你才意识到这意味着什么。但你已经答应了，要收回似乎更难。

因素三：觉得没有资格说不

你可能觉得自己的需求没有别人的需求重要。你可能觉得我拒绝别人是不对的，因为别人帮过我，或者我应该更感恩。这些想法背后有一个共同的假设：你的时间和能量不如别人的重要。

因素四：回避拒绝

当你知道自己无法满足某个请求时，你可能会选择拖延回应、回避接触、假装忘记，而不是直接说不。不是因为你不想处理它，而是因为你害怕看到对方失望的反应。你回避的其实不是那个请求本身，而是那个对方可能不高兴的可能性。

## 三、边界不是什么，是什么？

| 边界不是 | 边界是 |
| --- | --- |
| 拒绝所有人 | 选择哪些请求可以接受、哪些不能 |
| 冷漠或不在乎 | 保护自己已有的能量，以便在你选择时说好时能够真正投入 |
| 一次性的决定 | 一个需要反复练习和调整的动作 |
| 需要对方同意才能生效 | 只需要你执行就会生效 |

你可能一直把边界理解为一种攻击性行为，你做了一些让别人不舒服的事。

但边界更接近一种保护性行为：你在保护自己的时间、注意力和能量，而不是在攻击别人。

当你不再把边界看作是对别人做的事，而是为自己做的事，它就会变得更容易一些。

## 四、如何开始建立边界？

建立边界是一个渐进的过程，可以从边界练习的难度层级中，选择当前对你来说最可行的位置。

第一层：为自己创造一个延迟回应的空间

当你听到一个请求时，不急着回答。给自己说我需要想一下，或者说我晚点回复你。这句话会给你留出时间来评估：我真的想做这件事吗？我有时间吗？我说好之后会感到什么？这个练习不涉及任何拒绝，它只是给你时间去做一个更完整的决定。

第二层：练习说一个小的 “不”

在那些你不太在意结果的关系中，练习一个小的、低风险的拒绝。比如拒绝一个你不感兴趣的活动邀请，或者礼貌地表示你无法帮忙。你不需要解释太多，只需要说这次我去不了，或者这次我帮不上忙。这个练习的目的是让你体验一下：在你说不之后，对方并不会离开你。你仍然安全。

第三层：是的，但是……

如果你觉得直接说不太难，可以尝试用有条件的好来替代全部拒绝。“是的，但我只有半小时”或者“是的，但我需要下周才能处理”。这仍然是一个边界，但它比不更容易说出口。它表明你愿意在某些条件下提供帮助，而不是无条件地接受。

第四层：在重要关系中表达你的真实限制

这是最难的一层，也是最重要的。当你在一段重要的关系中感到过度消耗时，你可以告诉对方：我很想帮你，但我目前的能量不太够，这次可能做不到。或者说：我需要一些安静时间，我明天再回复你好吗？

你不需要为你的限制道歉。你只是在陈述一个事实。而事实不需要被原谅。

## 五、你可能会遇到的不适

当你开始建立边界时，你可能会遇到一些内在的不适：

- 你可能会觉得自己很自私
- 你可能会担心对方不再喜欢自己
- 你可能会在说完不之后反复想“是不是做错了
- 你可能会不习惯把自己的需求放在前面

这些不适是正常的。你正在做一件你过去不常做的事。你的大脑在告诉你这不熟悉，而不是这是错的。你可以为这些感觉留出空间。你不需要消除它们才能继续。
