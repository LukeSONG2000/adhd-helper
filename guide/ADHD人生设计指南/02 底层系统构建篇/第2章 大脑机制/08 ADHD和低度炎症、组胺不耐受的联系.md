# ADHD和低度炎症、组胺不耐受的联系

在探讨ADHD的生理基础时，我们通常聚焦于大脑的神经递质。但近年来的医学研究把目光投向了另一个关键领域：身体的免疫系统与组胺代谢。

在了解这部分内容前，我们需要先树立一个科学前提：组胺不耐受或身体炎症，可能会加重或模拟ADHD的症状，但这并非意味着所有ADHD都是由它们引起的。

厘清两者的关系能帮我们排除自我诊断的焦虑；而了解这些机制，能为我们提供一条容易被忽视的日常调整思路：通过排查身体的隐性炎症与不耐受，卸下部分生理负荷，让原本吃力的大脑运行得更轻松。

## 一、 ADHD中常见的身体共病和炎症表现

大量流行病学研究发现，ADHD群体往往更容易被一些慢性炎症或免疫相关的问题缠上。如果你长期有以下情况，这并非巧合，它们往往在暗中消耗着你本就有限的精力：

1. 过敏与呼吸道问题：换季时雷打不动的过敏性鼻炎，早上起来总是连打十几个喷嚏、鼻塞导致大脑

缺氧发懵；或者是慢性咽炎、哮喘，甚至小时候扁桃体动不动就发炎。

2. 皮肤与黏膜问题：特应性皮炎、湿疹反复发作，尤其是在压力大、熬夜或情绪崩溃后，皮肤颜色会

改变；或者嘴里总是莫名其妙地长口腔溃疡。

3. 食物不耐受、肠胃敏感：吃了某些特定食物后容易腹胀、腹泻；或者是乳糖不耐受导致的频繁肠胃

不适。这常常表现为肠易激，一紧张或吃错东西就立刻想跑洗手间。

4. 免疫反应剧烈：普通人感冒可能只是流鼻涕，你一感染就容易发高烧，或者引发强烈的急性炎症反

应，恢复期也比别人长得多。

5. 日常炎症：除了上述表现，如果你长期存在持续的疲惫与脑雾（睡够了也觉得大脑蒙着纱）、没有

剧烈运动却总觉得肌肉酸沉、关节僵硬，或者不明原因的情绪低落与烦躁，说明身体可能正处于炎症负荷中。

## 二、炎症与组胺是如何影响大脑的？

目前的科学共识认为，这本质上是神经内分泌系统与免疫系统之间的交互失调。

1. 低度炎症的累积

ADHD的神经系统长期处于高负荷状态。长期的压力、睡眠剥夺或情绪紧绷，会让身体持续释放皮质醇。这种压力会激惹免疫系统，释放低水平的炎症因子。这些因子能穿透血脑屏障，干扰神经发育与多巴胺的代谢。这直接导致了我们在日常生活中的感受：哪怕什么都没做也觉得极度疲惫；多巴胺需求异常，总是渴望高糖高油的食物；注意力严重溃散。

2. 组胺的过度觉醒

组胺不仅是引发过敏的化学物质，它本身也是重要的神经递质，参与调节觉醒、警觉性、注意力和动机。当体内缺乏足够的二胺氧化酶（DAO，负责在肠道分解食物中的组胺）时，组胺会在体内蓄积。过高的组胺会让大脑处于一种“过度觉醒”状态，表现为分心、烦躁、入睡困难。这些表现与ADHD的过度活跃/冲动症状高度重叠，这也是为什么有些人会将其误认为是假性ADHD。

3. 两者的恶性循环

组胺本身是一种强烈的促炎介质。组胺蓄积会加重身体的炎症反应，而长期的炎症又会破坏肠道黏膜屏障，导致更多未分解的组胺进入血液。在这个循环下，大脑的执行功能会进一步受损。

4. 焦虑抑郁与躯体化：共享一条炎症通路

长期的心理压力（如ADHD带来的持续挫败感、焦虑）会过度激活身体的压力系统，导致皮质醇长期异常分泌。这会激惹免疫系统，释放低水平的炎症因子（如CRP、IL-6）。

这些外周炎症因子会通过多种路径影响大脑，干扰多巴胺等神经递质，导致动力缺失和情绪低落；同时，它们也会影响外周神经，直接作用于疼痛感知通路。这或许能解释为什么躯体化症状（如慢性疼痛、疲劳）在焦虑抑郁人群中如此常见。

5. 基因层面的初步线索与争议
- DAO基因：2024年一项针对ADHD儿童和青少年的初步研究发现，在303名参与者中，78.8%的人至少携带一个与DAO功能减弱相关的AOC1基因变异。但也有研究同时指出，没有发现DAO缺乏与ADHD的严重程度存在关联。

## 三、 生活观察：如何判断自己是否受组胺或炎症影响？

如果你怀疑自己存在这方面的问题，可以通过以下线索进行自我观察，不要盲目对号入座：

1. 饮食触发：在摄入了富含组胺的食物（如陈年奶酪、腌制肉类、红酒、发酵食品、菠菜、牛油果、

剩菜）后，多动、烦躁或注意力涣散显著加剧。

2. 伴随症状：经常伴随偏头痛、荨麻疹/湿疹、心慌、痛经或肠易激综合征。
3. 睡眠模式：身体很累，但大脑像开运动会一样无法关机。
4. 季节性波动：在花粉季或过敏高发期，ADHD症状明显更难控制。

## 四、 应对的边界与行动思路

看到这里，请尽量把它当成一个可以主动干预的变量，而不是一个新的绝症。抗炎、降组胺的生活方式，本质上是在给你的神经系统减负。请遵循以下安全原则：

1. 排查与记录饮食日记：不要自行长期严格忌口（以免营养不良）。详细记录吃了什么、多久后出现

症状，找到触发你反应的特定食物。

2. 温和的抗炎饮食与减少刺激源：减少高糖和深加工食品，多吃富含Omega-3的食物；优化居住环

境，定期清理空调、减少尘螨和霉菌。

3. 谨慎对待补充剂（如DAO酶）：如果在医生或营养师指导下，确认自己有组胺不耐受，尝试补充

DAO酶可能是一个辅助选项（相当于在肠道临时加派分解）。但这属于锦上添花，绝不能替代低组胺饮食，且需注意不同产品的酶活性差异很大。

4. 不要自行停用ADHD药物：如果你正在服药，任何饮食或补充剂的调整都应与医生沟通。
5. 寻求专业指导：带着你的记录去咨询消化科、过敏科医生或注册营养师，在专业指导下进行排查。

了解低度炎症与组胺不耐受，是为了让我们在身体发出警报时多一个观察的角度。如果大脑状态在吃了某些东西或身体过敏时明显变差，那就倾听身体的声音，我们可以针对性地给大脑减负。
