# 激素与ADHD的关联：有时状态爆棚，有时彻底崩盘？

## 阅读本节后你将理解：

- [ ] 你的ADHD药物为什么有时候失灵
- [ ] 如何读懂身体的激素信号，而不是和它对抗

## 一、激素与ADHD的关联

激素对大脑功能的影响是广泛存在的。研究显示，甲状腺功能与ADHD症状存在关联，无论男女都可能受到影响：

| 甲状腺功能与ADHD | 表现 |
| --- | --- |
| 促甲状腺激素（TSH）水平与多动行为呈正相关 | TSH水平越高，多动症状越明显 |
| ADHD儿童中TSH值普遍偏高 | TSH与多动、冲动症状显著相关 |
| 甲状腺功能异常会加剧注意力问题 | 可能让ADHD症状更难控制 |

这说明激素对ADHD的影响是双向的，激素水平的波动都可能直接影响ADHD症状的严重程度。

## 二、女性容易受激素影响

虽然激素影响是普遍的，但女性确实更常注意到激素与ADHD的关联，因为女性的生理特征让这种影响更容易被感知。

雌激素与多巴胺的协同关系

雌激素会促进多巴胺的释放和功能。当雌激素水平下降时，多巴胺水平也会随之下降。而ADHD大脑本身就已经缺多巴胺了。

| 雌激素状态 | 对ADHD大脑的影响 |
| --- | --- |
| 雌激素水平稳定 | 多巴胺系统运作相对稳定 |
| 雌激素水平下降 | 多巴胺水平随之下降，症状可能加重 |
| 雌激素水平上升 | 多巴胺功能增强，症状可能缓解 |

## 三、女性激素波动的关键阶段

女性一生的激素水平并非恒定的，而是在不同阶段发生系统性变化。这些变化可能对ADHD症状产生显著影响：

| 阶段 | 激素变化 | 对ADHD的影响 |
| --- | --- | --- |
| 青春期 | 雌激素水平开始上升，但波动不稳定 | 症状开始显现或加重，很多ADHD女孩在这个阶段，第一次被注意到状态起伏很大 |
| 生理期前（黄体期） | 雌激素下降，孕激素升高 | 多巴胺水平随之波动，注意力更散，情绪更容易失控，容易感到能力突然下降 |
| 孕期（尤其是孕晚期） | 雌激素持续升高 | 部分ADHD女性的症状会暂时缓解，但伴随身体变化和疲劳，也可能出现新的挑战 |
| 产后 | 雌激素急剧下降 | ADHD症状可能迅速反弹，同时伴随睡眠剥夺、荷尔蒙急剧变化，执行功能压力陡增，容易被误判为产后抑郁 |
| 更年期 | 雌激素长期下降 | 以前还能凑合的应对方法可能突然失效，注意力、记忆力、情绪稳定性全面受到挑战 |

### 不同阶段可以试试这些方向

【青春期】

你可能在这个阶段第一次感受到自己好像和别人不太一样。激素水平的波动让情绪和注意力的起伏更加明显。可以记录自己的状态变化，识别哪些时期更容易感到混乱或疲惫。如果可能，和信任的成年人（家人、老师、医生）沟通你正在经历的困难，减少独自面对的孤立感。

【生理期前（黄体期）】

这是很多ADHD女性感觉能力突然下降的阶段。注意力更散、情绪更容易起伏、启动更加困难。你可能会觉得自己退步了，但这不是你的问题，是多巴胺系统暂时失去了雌激素的支撑。可以在这个阶段适当减少对任务的要求——不要用状态好的标准来要求自己，允许自己用最低可接受状态来完成工作。如果可行，在可能的情况下把高难度任务安排在月经结束后的1-2周内，此时雌激素水平上升，对多巴胺系统的支持也会增强。

【孕期（尤其是孕晚期）】

部分ADHD女性在这个阶段会感觉症状暂时缓解，但也可能因为身体变化和疲劳出现新的挑战。如果你在服用ADHD药物，建议与医生讨论是否需要调整方案。适当减少任务量，把精力留给最重要的事。

【产后】

雌激素急剧下降，ADHD症状可能迅速反弹，同时伴随睡眠剥夺。这可能是最容易被误判为产后抑郁的阶段。如果你在产后感觉突然不行了，可以考虑与医生讨论是否与ADHD相关，而不仅仅是情绪问题。寻求家人和伴侣的实质性支持，你需要的不只是情感安慰，还有实际的休息时间。

【更年期】

雌激素长期下降，以前还能凑合用的应对方法可能突然失效。如果你发现以前能用的方法不管用了，可以考虑重新评估自己的用药方案或调整应对策略。允许自己在这个阶段重新学习如何与自己的大脑相处，你不需要沿用二十年前的方法，你可以为自己重新设计一套适合当前状态的系统。

## 四、女性往往承担社会期待

| 社会对女性的期待 | 现实中你的感受 |
| --- | --- |
| 要细心、有条理 | 东西总是乱，记不住细节 |

| 要情绪稳定、温和 | 情绪起伏大，有时会爆发，有时会自责很久 |

## 五、男性睾酮和ADHD的关系

2024年一项大规模研究给出了相对明确的结论：没有证据表明睾酮对ADHD风险有因果作用。 ADHD诊断率的性别差异，可能更多与症状表现有关：男性更容易表现出外显行为（多动、冲动、沉迷），因此被更早识别；女性症状更内化，更容易被漏诊。目前的诊断标准更倾向于识别多动型行为，而不是注意力分散型，这也是影响因素之一。

对于男性ADHD者，激素波动的幅度不如女性周期那么剧烈，但甲状腺功能的稳定同样会影响症状表现。激素管理对男女都可能适用，只是适用的节奏和方式不同。

## 六、了解这些规律，就是了解自己

❤️激素确实会影响你的状态，但它不会决定你的全部。知道激素的存在，不是为了让你觉得

自己的大脑不受我控制，而是让你在状态不好的时候少一个自我否定的念头。周期会过去，变化也会过去，而你知道自己在经历什么本身，就是一种支撑。你对这些波动的判断，决定了它们如何影响你。

如果你发现自己在某些时间段症状更明显，可以考虑：

- 记录症状变化周期：了解自己的症状波动规律，比在状态差时责备自己更有用
- 在症状加重的时期，调整对任务的要求：允许自己用最低可接受状态来度过
- 如果你正在进行药物治疗，可以咨询医生是否需要根据周期调整剂量

激素是ADHD大脑的调节器之一。它不会定义你是谁，但它会告诉你：你不需要在状态不好的时候还要求自己一切如常。
