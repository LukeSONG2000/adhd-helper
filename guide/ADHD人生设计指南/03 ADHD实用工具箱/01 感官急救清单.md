# 感官急救清单

感官过载随时可能发生，你需要在它发生之前就知道该怎么做。

感官过载的体验是：声音变得刺耳、灯光变得刺眼、皮肤感到不适、思绪混乱、只想逃离当前的环境。它可能持续几分钟，也可能持续一整个下午。你不需要“忍受它过去”，你可以用一些快速可执行的动作来降低它的强度。

以下清单按感官分类，你可以根据当前触发你的是哪一种感官，选择对应的急救动作。在感官过载的早期干预，比已经崩溃后再处理要有效得多。

## 听觉过载

当声音变得太多、太杂、太持续时：

| 动作 | 说明 |
| --- | --- |
| 戴上降噪耳机或耳塞 | 即使不放音乐，也能显著减少环境音的输入 |
| 切换到单一声音源 | 用雨声、风扇声、白噪音覆盖混乱的环境音 |
| 离开当前声音环境 | 去一个更安静的空间，哪怕只待3分钟 |
| 用手掌轻轻覆盖耳朵 | 施加轻微压力，减少声音输入的同时提供触觉安抚 |

## 视觉过载

当光线太强、视野太杂、信息太多时：

| 动作 | 说明 |
| --- | --- |
| 闭上眼睛30-60秒 | 时切断视觉输入，让大脑“重启”视觉处理 |
| 调暗灯光或切换到暖色光 | 关闭顶灯，打开台灯或使用暖色光源 |
| 将视线聚焦在一个单一的、安静的物体上 | 比如一杯水、一堵白墙、窗外的树 |
| 用手遮挡视野中的杂乱区域 | 减少视野中的信息量 |

## 触觉过载

当衣物材质、标签、温度、湿度让你感到不适时：

| 动作 | 说明 |
| --- | --- |
| 换掉那件让你不舒服的衣服 | 这是一个可以立即采取的动作，你不需要“忍到回家” |
| 调整温度或湿度 | 开窗、加一件外套、脱掉一层 |
| 用柔软的织物包裹自己 | 一条柔软的毯子可以提供安全感和触觉安抚 |
| 按压或拥抱自己 | 双臂交叉抱紧自己，施加均匀的压力，帮助神经系统重新校准 |

## 嗅觉过载

当某种气味让你感到烦躁或恶心时：

| 动作 | 说明 |
| --- | --- |
| 离开当前气味环境 | 去另一个空间呼吸不一样的空气 |
| 开窗通风 | 让新鲜空气进入，打破气味的滞留 |
| 闻一个你熟悉且舒适的气味 | 比如自己的衣袖、一件干净的衣物 |
| 携带一个“气味锚点” | 一小块柑橘皮、一小袋干燥的茶叶、一片干净的棉布——在需要时闻一下 |

## 通用急救动作（适用于所有类型的过载）

| 动作 | 说明 |
| --- | --- |
| 离开当前环境 | 走开3-5分钟，切断持续输入的感官刺激 |
| 用冷水冲洗手腕和脸部 | 冷刺激可以唤醒身体，打断累积的感官负荷 |
| 找一个黑暗、安静的空间 | 果可能，在洗手间、空房间、车内坐几分钟 |
| 深呼吸3次 | 缓慢地吸气、屏住3秒、缓慢地呼气，重复3次——不需要长时间冥想，3次就够了 |
| 告诉身边的人“我需要休息几分钟” | 你不一定需要解释原因，只需要让周围的人知道你不要被持续打扰 |

## 🧾急救清单的使用说明

- 在需要的时候立刻使用，而不是等到完全崩溃

感官过载有一个累积的过程。如果你在早期阶段就干预，只需要一个简单的动作就可以减轻负荷。如果你等到已经过载到了极限才行动，你需要更长的恢复时间。优先在感觉到“开始不舒服了”的时候就采取动作。

- 根据你的敏感类型，提前准备你的工具

如果你知道自己对声音特别敏感，把降噪耳机放在你容易拿到的地方。如果你对光线特别敏感，随身带一副太阳镜或准备可调光的台灯。提前准备不会防止所有过载，但会让你在过载发生时有一个更快的响应方式。

- 使用时不评判自己

你不需要因为“我需要离开一下”而感到抱歉。你的神经系统正在处理它不擅长处理的信息量。离开不是逃避，是你为自己做的事。你不需要为照顾自己的神经需要而道歉。
