# 睡眠观察表

睡眠问题对ADHD来说非常普遍，入睡困难、睡前大脑停不下来、早上起不来、白天疲惫但晚上清醒。你可能尝试过各种睡眠卫生建议：早睡、关手机、喝热牛奶。如果这些方法对你有用，你可能不会在这里。如果它们没有用，可能不是因为“你做得不够”，而是因为你的睡眠问题与ADHD大脑的节律和警觉模式有关，而你可能还没有针对它进行观察和记录。

这张观察表的目的不是让你睡得更早，而是帮你看到你自己睡眠的规律。当你看到规律，你就有了调整的依据。没有数据之前，所有的调整都是猜测。

以下是一个你可以直接开始使用的睡眠观察模板，以及使用说明。

## 一、睡眠观察表模板

你可以用一本笔记本、手机备忘录或任何方便的工具来记录以下内容。不需要每天都填满，但连续记录5-7天会让你开始看到自己的模式。

| 记录项 | 内容 | 记录时间 |
| --- | --- | --- |
| 今天几点起床的？ | 起床时间 | 起床后30分钟内 |
| 起床时感觉如何？（1-5分） | 1=完全没睡醒，5=清醒有精力 | 起床后30分钟内 |
| 今天白天困吗？大概在什么时间？ | 困的程度（1-5分）和具体时间段 | 白天/晚上睡前记录 |
| 今晚几点上床的？ | 睡觉时间 | 睡前 |
| 躺下后大约多久才睡着？ | 估计分钟数 | 次日早晨回忆 |
| 如果你在睡前感到大脑停不下来，那是关于什么的内容？ | 句话概括（如“工作明天要做的事”“对某段对话的反刍”） | 次日早晨回忆 |
| 昨晚你做了什么特别的睡前活动？ | 比如：看手机、读书、听音乐、洗澡、吃东西 | 次日早晨回忆 |
| 你觉得自己昨晚睡得怎么样？（1-5分） | 1=很差，5=很好 | 次日早晨回忆 |

## 二、附加记录项（可选）

如果你有精力记录更多信息，以下条目会提供更完整的图像：

| 附加记录项 | 为什么重要 |
| --- | --- |
| 昨晚大概几点睡着的？ | 帮助你观察你的自然入睡时间点 |
| 今天是否有咖啡因摄入？什么时间？ | 咖啡因在摄入后6-8小时内仍可能影响睡眠质量 |
| 今天是否有运动？什么时间？ | 运动时间会影响入睡，有时运动太晚会提高警觉 |
| 今天是否经历了感官过载或情绪崩溃？ | 这些事件会影响你当晚的入睡难度和恢复状态 |
| 如果你半夜醒来，大概在什么时间？ | 可以帮助你区分是入睡困难还是睡眠维持困难 |

## 三、如何使用这些数据？

在收集5-7天的数据之后，你可以回看并寻找以下模式：

入睡时间模式：

- 你通常在什么时间段入睡？是持续在某个固定时间，还是每天都不同？
- 如果你发现你的入睡时间集中在某个区间（比如凌晨12:30-1:30），那是你身体的自然入睡窗口。在这个窗口入睡，比你强迫自己在11点睡要容易得多。

醒来状态模式：

- 你在哪一天感觉醒来状态更好？前一天做了什么不同的事？
- 你在哪一天感觉醒来状态更差？前一天发生了什么？
- 这些信息可能指向对你有帮助的行动——比如某种睡前活动更有利于你恢复。

睡眠质量的影响因素：

- 在睡得好的那几天，你做了什么？在睡得差的那几天，发生了什么？
- 可能有些模式出现：比如如果在睡前有感官过载，那一晚的睡眠质量更低，或如果白天有运动，入睡会更快。

白天困倦的模式：

- 你的困倦通常在什么时间出现？那个时间是否与你的任务模式相符？
- 如果你发现每天下午2-3点你都会感到困倦，你可以在那个时段安排不需要高度专注的任务。

## 四、使用建议

连续记录至少7天

1-2天的记录可能会让你看到一些信息，但7天的记录会让你看到规律。你不需要一直记录下去——7天足够让你对你的睡眠模式有一个初步的了解。

不需要追求“好睡眠”才能记录

你可能在记录期间有一些睡得好的夜晚，也有一些睡不好的夜晚。两者都值得记录。睡得不好的夜晚提供的信息，可能比睡得好的夜晚更多。

记录不需要完美

你不需要每天准时记录，也不需要填写所有项目。只记录那些你能够记录的部分。不完整的数据也比没有数据更有用。

## 五、一张精简版随身卡

如果你无法每天填写完整的观察表，可以用以下精简版本，贴在床头或保存在手机里：

- 今天几点起的？＿＿＿＿ 醒来状态（1-5）：＿＿＿＿
- 昨晚几点睡的？＿＿＿＿
- 躺下后大约多久睡着？＿＿＿＿分钟
- 睡得怎么样？（1-5）：＿＿＿＿
- 一个词描述昨晚的睡眠：＿＿＿＿

你可以在醒来后2分钟内完成这个记录。即使只有这些信息，连续记录一周也会让你开始看到自己的睡眠模式。

## 六、当你看到模式之后

记录本身不会改变你的睡眠，但记录的结果可以指导你的行动。当你看到了你的模式——比如你发现自己总是在11点之后才感到清醒、或者总是在凌晨某个时间醒来——你可以把这些信息作为你调整的起点。

你不需要成为一个早睡早起的人。你只需要成为一个知道自己的睡眠如何运作，并能在运作方式内做出合适安排的人。
